# Switch between Hyprland and Niri

1. Set `custom.desktop-session.compositor` in `hosts/desktop/desktop.nix` to `"hyprland"` or `"niri"`.

	```nix
	custom.desktop-session.compositor = "niri";
	```

2. Run `nrs` to rebuild and apply the configuration.
3. Log out, then log in through Ly to start the selected compositor.

Changing the selector does not replace a running compositor. A compositor reload alone does not apply this switch.

NixOS installs only the selected compositor. Home Manager selects its configuration and desktop-specific Zen browser defaults. Waybar runs only in Hyprland. Niri also gets X11 application support through `xwayland-satellite`.

## Restore the managed Hyprland configuration

1. Select `"hyprland"` in `hosts/desktop/desktop.nix`.
2. Run `nrs`.

Home Manager replaces an unmanaged `~/.config/hypr/hyprland.conf` with the repository configuration. Before replacement, it copies a regular file to `hyprland.conf.unmanaged.<timestamp>` in the same directory. An autogenerated stub no longer blocks activation when switching back from Niri.

Edit the Nix files under `packages/hyprland/` to change Hyprland settings. The generated file in `~/.config/hypr/` is not the source configuration.

## Use wallpapers in either compositor

1. Put images in `~/wallpapers`. Supported extensions are `.jpg`, `.jpeg`, `.png`, `.gif`, and `.webp`.
2. Log in to restore the last wallpaper or choose a random image on the first login.
3. Press `Super+Shift+W` to choose a random wallpaper and update Matugen colors.

Both compositors use one `awww-daemon` user service and the same `~/.cache/matugen/last-wallpaper` cache. The shared scripts are in `system/desktop-session/wallpapers/scripts/`. An empty wallpaper directory leaves the session running without a wallpaper.

## Switch between light and dark mode

1. Run `nrs` to install the shared theme command and both compositor bindings.
2. Press `Super+Shift+D` to toggle light and dark mode in either desktop.

Use `desktop-theme light` or `desktop-theme dark` to select a mode from the terminal. The first login defaults to dark mode.

The command saves your choice in `~/.local/state/desktop-theme/mode`. Future logins, wallpaper changes, and compositor switches keep that mode.

The shortcut updates GTK themes and the desktop color preference for applications that follow the system setting. It also regenerates Matugen colors for Kitty and new Zsh sessions. Hyprland's Waybar follows the GTK theme. Applications with their own appearance setting can ignore the system preference.

The wallpaper stays unchanged. Without a valid cached wallpaper, Matugen uses a fallback accent color. The command uses [Matugen's light and dark modes](https://github.com/InioX/matugen/wiki/Usage).

## Use the desktop font defaults

1. Run `nrs` to install Figtree and apply the font defaults.
2. Log out, then log in so applications receive the Qt font integration setting.

Figtree is the default font for GTK applications, Qt applications that use the GTK3 platform plugin, Rofi, and Hyprland's Waybar. Fontconfig also uses Figtree for generic proportional fonts. Applications and websites that select their own fonts can ignore these defaults.

Kitty keeps JetBrains Mono Nerd Font at size 12. Generic monospace fonts also use JetBrains Mono Nerd Font.

Edit `fonts` in `system/desktop-session/appearance-constants.nix` to change the font names or the desktop font size. Both compositor selections use these values. Font defaults do not change the light and dark mode settings.

## Adjust terminal blur in Niri

1. Edit `blur` in `system/desktop-session/appearance-constants.nix` to change blur strength in both desktops.
2. Run `nrs` to apply the configuration.

Niri uses [native background blur](https://niri-wm.github.io/niri/Window-Effects.html#blur) for Kitty, with four passes and an offset of five. Kitty keeps its 90% background opacity without dimming text. Normal blur also includes windows behind the terminal, matching Hyprland's disabled xray setting.

Niri's normal blur is experimental. It can disappear during window opening, closing, and tiled-window dragging. See [Niri's non-xray limitations](https://niri-wm.github.io/niri/Window-Effects.html#non-xray-effects-experimental).

## Match window spacing between desktops

1. Edit `gaps` and `rounding` in `system/desktop-session/appearance-constants.nix`.
2. Run `nrs` to apply the configuration.

Both desktops use five-pixel outer margins, eight pixels between tiled windows, six-pixel rounded corners, and no borders. Hyprland applies `gaps_in = 4` to each adjacent window. Niri uses `gaps 8` and [struts](https://niri-wm.github.io/niri/Configuration:-Layout.html#struts) of `-3` to match the outer margins. Niri's focus ring is disabled so it does not cover the gaps or tint transparent windows.

Niri prevents applications from opening maximized to the screen edges because that state bypasses gaps. Use `Super+F` for a full-width column that keeps the margins. Fullscreen through `Super+Shift+F` still covers the screen.

## Use the Niri key bindings

1. Run `nrs` to install the bindings and their helper applications.
2. Log out, then log in to apply the screen-reader session environment.
3. Press `Super+Shift+/` to show the important-hotkeys overlay.
4. Use the [Niri key binding reference](../../packages/niri/KEYBINDINGS.md) for the complete shortcut list and changes from the previous configuration.

`Super` is the Windows key. Press `Super+D` for Rofi and `Super+R` to cycle column widths. Move windows with `Super+Ctrl` and an arrow key. `Super+Shift` and an arrow key now focus monitors.

Use `Super+M` to maximize a window to the screen edges. Exit Niri with `Super+Shift+E` or `Ctrl+Alt+Delete`.

## Validate without activating the system

Run the regression checks from the repository root:

```sh
nix eval --impure --json --file home/desktop/tests/evaluate.nix
python3 home/desktop/tests/test_hyprland_config.py
python3 home/desktop/tests/test_wallpapers.py
python3 home/desktop/tests/test_theme_mode.py
python3 home/desktop/tests/test_niri_keybindings.py
```

The checks evaluate both compositor selections, enforce exclusive sessions and packages, and verify the shared wallpaper configuration. They also check portals, browser defaults, font defaults, terminal blur, Waybar, and both system derivations. The key binding test compares every active binding against the configured Niri package's upstream defaults and checks for shortcut conflicts. Nix substitutes the shared appearance values into `packages/niri/config.kdl`, then validates the result with the selected Niri package when building the managed file.

The session setup follows [Niri's systemd integration](https://niri-wm.github.io/niri/Example-systemd-Setup.html). Selecting Niri removes Waybar's package, configuration, and user service without changing the Hyprland bar.
